easyPeasy — My Personal Study Space
An AI-powered study assistant built to turn notes, text, files, and links into structured learning tools.

Features
AI Summaries & Notes: Condense long study material into clear, structured key points.
Interactive Flashcards & Quizzes: Generate active-recall decks and practice questions automatically.
Panic Mode: One-click calming mode with a soothing piano soundtrack for stressful study sessions.
Light & Dark Mode: Clean pastel interface with seamless theme switching.

 How to Run
1. Clone or download this repository.
2. Open `index.html` in any modern web browser.
